#Linux File Management Workspace

##Objective

The objective of this project was to practice Linux command-line
operations for managing files and directories using Ubuntu and Bash.

##Environment

- Operating System: Ubuntu
- Shell: Bash
- Terminal: Linux Terminal

##skills Demonstated

- Directory navigation
- Directory creation
- File creation
- File viewing
- File copying
- File moving
- File renaming
- File deletion
- File searching
- File information
- Command history
- Basic file permissions

##Commands Practiced

| Command | Purpose |
|---|---|
| pwd | Shows current directory |
| ls | Lists files and directories |
| cd | Changes directory |
| mkdir | Creates a directory |
| touch | Creates an empty file |
| cat | Displays file contents |
| cp | Copies files |
| mv | Moves or renames files |
| rm | Removes files |
| rmdir | Removes empty directories |
| find | Searches for files/directories |
| head | Displays beginning of a file |
| tail | Displays end of a file |
| wc | Counts lines, words and characters |
| file | Identifies file type |
| stat | Displays detailed file information |
| history | Displays previously executed commands |
